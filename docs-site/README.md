# Lynx Capacitor Documentation Site

This is a standalone static documentation site for `lynx-capacitor` that:

- Introduces the project
- Provides step-by-step getting started instructions
- Lists all plugins with current support status
- Links to the official Capacitor documentation for full API reference

## Publishing

You can host this anywhere as a simple static site. The full source for the adapter is at [github.com/lynx-family/lynx-capacitor](https://github.com/lynx-family/lynx-capacitor).

## Local testing

Open `index.html` directly in a browser — it's completely static, no build step needed.
