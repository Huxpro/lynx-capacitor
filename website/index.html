What is this?

🎯 Native Bridge Adaptation

Reimplements the @capacitor/core interface using Lynx's NativeModule API. All official Capacitor plugins from npm work without any code changes.

📦 35 Official Plugins

Every official plugin from the Capacitor 8 documentation is included and linked to the official native iOS implementations.

🔗 Zero Changes

Install the official npm packages, add one build alias, and you're done. No need to fork or patch any plugins.

✅ Fully Tested

27/35 plugins pass automatic smoke tests on iOS Simulator. All interactive and credential-gated plugins are wired and ready.

Getting Started

1

Install packages

Install the official Capacitor plugins you need, then add the adapter:

npm install @capacitor/device @capacitor/preferences @lynx-capacitor/core
2

Add the build alias

Add this alias to your Lynx Rspeedy config to redirect @capacitor/core to our adapter:

// lynx.config.ts
resolve: {
  alias: {
    '@capacitor/core': require.resolve('@lynx-capacitor/core'),
  },
}
3

iOS: add the native dependency

In your iOS Podfile, add the adapter pod which automatically includes all Capacitor plugins:

pod 'LynxCapacitorRuntime', :path => 'path/to/lynx-capacitor/ios/official'
4

Register the native module

In your Lynx view controller, register the bridge:

[lynxView registerNativeModule:[LynxCapacitorBridge class]];
